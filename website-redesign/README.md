# Новый дизайн сайта Rovno

Эта папка — источник истины для передаваемого дизайн-прототипа. Это самостоятельный Next.js-проект для переноса дизайна в существующее Vite-приложение Rovno. Добавление папки само по себе не меняет опубликованный сайт и маршруты приложения.

## Локальный запуск

Нужен Node.js 20.9 или новее.

```sh
cd website-redesign
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000. Если порт занят нашим локальным макетом, запустить `npx next dev --hostname 127.0.0.1 --port 3001`.

Проверка: `npm run build`. Никакие ключи Supabase или переменные окружения не нужны.

## Что передано

- Главная, блог, пример статьи /blog/whats-new-1-3.
- /offer, /privacy, /refund, /contacts с действующими текстами на момент переноса.
- Адаптив, полноэкранное мобильное меню, переключение цвета хедера над CTA и Шуриком.
- Согласованные анимации, курсор с увеличением до 30 px, плавная прокрутка Lenis.
- Оригинальные иллюстрации, SVG и шрифты в public/.
- /ui-kit, /button-effects и /cursor-effects — страницы проб, не для публикации.

## Интеграция в продукт

Основное приложение использует Vite, React 18 и React Router; этот прототип — Next.js и React 19. Нельзя заменять корневые package.json, src/, public/ или настройки приложения файлами этой папки. Компоненты и стили требуется адаптировать к существующим маршрутам и зависимостям. Next-специфичные части: app/layout.tsx, Metadata, usePathname в SiteCursor и SmoothScroll. Глобальные globals.css/landing.css нужно изолировать от интерфейса продукта. Ключи авторизации и серверная логика сюда не включены.

## Перед публикацией

- Заменить пустые обложки и иллюстрации статей реальными материалами.
- Уточнить текст первой статьи: версия 1.3 в описании и 1.5 в теле, повтор текста в разделе документов.
- Перенести две другие статьи: сейчас их карточки ведут на действующий rovno.ai.
- В app/layout.tsx пока установлен robots noindex/nofollow; снять при подготовке итоговой публикации.
- Перепроверить актуальность текстов документов, реквизитов и тарифов; соответствие ссылок plan=master/brigade согласовано с владельцем.
- Проверить на реальных iPhone/Safari и Android; локальные проверки выполнялись в Chromium.
- Проверить почту, звонки, регистрацию, демо и оплату после интеграции. Реальные платежи не выполнялись.
- ВКонтакте и Max пока отключены по просьбе владельца. Реквизиты находятся в контактах.

## Проверки до передачи

Локальные сборки проходили. Ранее проверены адаптив 320–1728 px, внутренние ссылки, загрузка изображений, меню, курсор, анимации и reduced-motion. Это проверки отдельного прототипа; интеграция в основное приложение и production-деплой ещё не выполнены.
